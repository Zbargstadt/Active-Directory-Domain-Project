# Active-Directory-Domain-Project ( IN PROGRESS )
This is the documentation of my Active Directory Home lab, designed to mimic a real-world enterprise environment. This will be hosted on my own PC using VMware workstation, the environment will include a windows 2022 server domain controller, a windows 11 enerprise client, and a osTicket server. Then once this project is finished I can use it to practice some real world tickets that one would receive in a help desk role.
